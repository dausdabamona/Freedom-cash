## Format Angka Indonesia

### Format Standar
```
Rp1.000.000 = 1 juta rupiah
Rp5.000.000 = 5 juta rupiah
Rp100.000.000 = 100 juta rupiah
Rp1.000.000.000 = 1 miliar rupiah
```

### Format Kompak
```
Rp5 Jt = 5 juta
Rp10 Jt = 10 juta
Rp5 M = 5 miliar
Rp10 M = 10 miliar
```

## Formula Kebebasan Finansial

### Formula Dasar
```
Kebebasan Finansial = Passive Income ≥ Biaya Hidup

Contoh:
Passive Income: Rp8.000.000
Biaya Hidup: Rp8.000.000
Coverage Ratio: 100% ✓ BEBAS!
```

### Perhitungan Freedom Score
```
Freedom Score =
  (Coverage Ratio × 40%) +
  (Runway × 30%) +
  (Debt Ratio × 20%) +
  (Asset Productivity × 10%)

Contoh:
Coverage: 50% → Score 20/40
Runway: 12 bulan → Score 30/30
Debt: 30% → Score 14/20
Productivity: 0.5%/bulan → Score 5/10
---
Total Freedom Score: 69/100 (Bagus!)
```

### Proyeksi Waktu
```
Bulan ke Kebebasan =
  LOG(Target Income / Current Income) /
  LOG(1 + Growth Rate)

Contoh:
Current: Rp3.000.000
Target: Rp8.000.000
Growth: 10% per tahun (0.797% per bulan)

Hasil: 120 bulan = 10 tahun
```

## Mengubah Mata Uang

Jika Anda ingin menggunakan mata uang lain:

1. Buka halaman **Settings**
2. Scroll ke bagian **Preferences**
3. Pilih mata uang dari dropdown:
   - IDR (Rp) - Rupiah Indonesia ← Default
   - USD ($) - US Dollar
   - EUR (€) - Euro
   - GBP (£) - British Pound
   - JPY (¥) - Japanese Yen
   - AUD (A$) - Australian Dollar
   - CAD (C$) - Canadian Dollar
4. Klik **Save Settings**

Semua angka akan otomatis dikonversi ke format mata uang yang dipilih.

## API dengan Rupiah

### Contoh Request
```bash

  -H "Content-Type: application/json" \
  -d '{

    "monthly_amount": 3000000,
    "growth_rate": 5,
```

```json
{

  "stability_score": 8
```

## Format Display vs Database

### Database (Number)
```sql
monthly_amount = 5000000
current_value = 500000000
```

### Display (Formatted)
```
Monthly Amount: Rp5.000.000
Current Value: Rp500.000.000
Compact: Rp500 Jt
```

### Input
User bisa input dalam format apapun, sistem akan parsing:
- `5000000` → Rp5.000.000
- `5.000.000` → Rp5.000.000
- `5 juta` → Rp5.000.000 (future feature)

## Utilitas Currency (Frontend)

### Import
```typescript
import {
  formatCurrency,
  formatCurrencyCompact,
  formatIndonesianNumber
} from '../utils/currency';
```

### Penggunaan
```typescript
// Format standar
formatCurrency(5000000)
// Output: "Rp5.000.000"

// Format kompak
formatCurrencyCompact(5000000)
// Output: "Rp5 Jt"

// Format kata
formatIndonesianNumber(5000000)
// Output: "5 juta"

// Dengan desimal
formatCurrency(5000000, {
  minimumFractionDigits: 2
})
// Output: "Rp5.000.000,00"
```

## Tips Sukses

1. **Mulai dari Yang Kecil**
   - Target awal: Rp500.000/bulan passive income
   - Naikkan bertahap setiap bulan
   - Konsisten lebih penting dari jumlah besar

2. **Fokus pada ROI Tinggi**
   - Property di lokasi strategis: 10-12%
   - Saham dividend: 5-7%
   - Bisnis online: 20-30%

3. **Diversifikasi**
   - Jangan hanya 1 sumber passive income
   - Target minimal 2-3 income engines
   - Mix property + saham + bisnis

4. **Monitor Bulanan**
   - Update actual income setiap bulan
   - Bandingkan dengan proyeksi
   - Adjust strategi jika perlu

5. **Kurangi Lifestyle Inflation**
   - Saat income naik, jangan naikkan gaya hidup
   - Reinvest semua kenaikan income
   - Maintain biaya hidup tetap
